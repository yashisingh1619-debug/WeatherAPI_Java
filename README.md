# 🌤️ Java Weather Application
Get real-time weather updates with a simple Java console application.

## ✨ Features
- Get real-time weather updates
- Displays current weather condition
- Shows current temperature
- User-friendly console interface
- Exception handling for smooth execution

## 🛠️ Technologies Used
- Java
- HttpClient
- wttr.in API

## ▶️ How to Run
1. Compile the program.
2. Run the application.
3. Enter the city name.
4. View the weather details.
